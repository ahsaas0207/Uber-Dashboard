🚕 Uber Ride Analytics Dashboard – Power BI

An interactive multi-page Power BI dashboard analyzing Uber ride bookings, revenue, and vehicle-wise performance across categories like Auto, Bike, Go Mini, Go Sedan, Premier Sedan, and Uber XL. Designed with a custom landing page for easy navigation between Overview and Vehicle views.

Key Features:

📄 Home Page

Custom-branded landing page with navigation buttons (Home, Overview, Vehicle)

📄 Overview Page

KPI cards for Complete Bookings (93K), Lost Bookings (57K), Revenue (52M), Total Distance, and Average Distance
Monthly/Quarterly trend of completed bookings and revenue
Revenue by Vehicle Type comparison
Top Pickup and Drop locations
Average Customer and Driver Ratings
Ride status breakdown: Completed, Cancelled, Incomplete

📄 Vehicle Page

Detailed vehicle-wise table with Customer Count, Revenue, Complete Bookings, Average Distance, and Lost Bookings

Tools Used: Power BI, Power Query, DAX
